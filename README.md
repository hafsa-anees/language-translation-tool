\# Language Translation Tool



\*\*Made by:\*\* \[Hafsa Anis]



\## Description

A web app that translates text between many languages.



\## Features

\- Select source and target language

\- Auto language detection

\- Translated text with a copy button

\- Text-to-speech (Listen button)

\- Retry system + backup translator (MyMemory) if Google fails



\## Technologies Used

\- Python

\- Streamlit (user interface)

\- deep-translator (Google Translate + MyMemory)

\- gTTS (text-to-speech)



\## How to Run

1\. Install libraries: pip install -r requirements.txt

2\. Run the app: streamlit run app.py
